# Hospital Management System

A console-based Hospital Management System written in **Java**,
built as part of the Advanced Java course at Dire Dawa University.

## Features
- Add, view, search, update, and delete patients
- View and add doctors
- Book and view appointments
- Create bills, view bills, mark bills as paid
- Input validation (no crashes on bad input)

## Tech
- Java (JDK 8+)
- Object-oriented design (classes, encapsulation)

## How to Run

```bash
javac HospitalSystem.java
java HospitalSystem
